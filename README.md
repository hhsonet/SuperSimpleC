# SuperSimpleC 🐛

A beginner-friendly C programming repository with small, focused exercises and one larger mini-project.

## Learning Path (Beginner → Advanced)

1. **TwoDigitFun** — sum of digits from a two-digit number
2. **digitOp** — apply operator to digits of a two-digit number
3. **mirror_alphabet** — mirror a lowercase letter (`a ↔ z`)
4. **rounding-float** — arithmetic rounding without `round()`
5. **topics/basic/array** — bubble sort trace walkthrough
6. **topics/functions** — function decomposition with factorial
7. **topics/pointers** — pointer-based swapping
8. **topics/strings** — string reversal and validation
9. **topics/files** — file handling and line counting
10. **topics/structs** — struct usage and aggregate calculations
11. **PracticeProblem/pp_mod_1** — multi-step equation/character challenge
12. **squid-game-player-manager** — modular menu-driven mini project with file input

## Repository Structure

- `/TwoDigitFun` - one focused starter exercise
- `/digitOp` - one focused digit-operator exercise
- `/mirror_alphabet` - one focused character arithmetic exercise
- `/rounding-float` - one focused arithmetic rounding exercise
- `/PracticeProblem/pp_mod_1` - assignment-style practice prompt
- `/topics` - topic-wise runnable examples
- `/squid-game-player-manager` - larger modular console project

## Build and Test

Use the compile-all script to validate all C files:

```bash
bash scripts/build_all.sh
```
