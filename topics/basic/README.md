# topics/basic

## Problem
Practice core array traversal and sorting trace output.

## Input
- No user input required for the included example

## Output
- Step-by-step sorting trace and final sorted array

## Sample Run
```text
Original array:
5 6 3 1 0
...
Sorted array:
0 1 3 5 6
```

## Compile and Run
```bash
gcc -Wall -Wextra -std=c11 /home/runner/work/SuperSimpleC/SuperSimpleC/topics/basic/array/bubble_sort_trace.c -o /tmp/bubble_trace
/tmp/bubble_trace
```

## Edge Cases
- Already sorted input arrays
- Reverse-sorted arrays
