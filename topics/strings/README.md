# topics/strings

## Problem
Read a word and print it in reverse order.

## Input
- One word (max length 99, no spaces)

## Output
- Reversed word

## Sample Run
```text
Enter a word (max 99 chars): hello
Reversed: olleh
```

## Compile and Run
```bash
gcc -Wall -Wextra -std=c11 /home/runner/work/SuperSimpleC/SuperSimpleC/topics/strings/reverse_string.c -o /tmp/reverse_string
/tmp/reverse_string
```

## Edge Cases
- Empty input
- Input longer than buffer
