# topics/pointers

## Problem
Swap two integers using pointers and a helper function.

## Input
- Two integers

## Output
- Values before and after swap

## Sample Run
```text
Enter two integers: 4 9
Before swap: a=4, b=9
After swap: a=9, b=4
```

## Compile and Run
```bash
gcc -Wall -Wextra -std=c11 /home/runner/work/SuperSimpleC/SuperSimpleC/topics/pointers/swap_with_pointers.c -o /tmp/swap_with_pointers
/tmp/swap_with_pointers
```

## Edge Cases
- Non-integer input
- Equal values
